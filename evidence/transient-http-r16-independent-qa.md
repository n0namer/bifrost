## Findings

1. **High — native SSE truncation contract regresses and existing tests fail.** `core/providers/utils/roundtripper.go:416` now passes `io.ErrUnexpectedEOF` to every native reader. For OpenAI, `core/providers/openai/openai.go:770-774` sends this through `ProcessAndSendError` (`core/providers/utils/utils.go:4372`), creating `IsBifrostError=true`, no 502, and generic `Error reading stream: unexpected EOF`, bypassing the semantic `SendStreamTruncatedError` path. Four existing tests for chat pre-first-byte, chat mid-stream, text and Responses fail with precisely this mismatch. Pre-first-byte native failure now stops the retry loop (`core/bifrost.go:7831-7833`) instead of its documented retryable upstream-connection error; mid-stream clients lose its documented error classification. The no-replay intent is valid: blindly restoring a retryable error after a potentially processed POST would reintroduce duplication. Repair must explicitly reconcile the native error contract with the no-replay boundary, update affected tests deliberately, and prove physical sends and downstream error semantics, including mid-stream and before any emitted chunk. This is a demonstrated compatibility/test regression, not a claim that retry must be restored.

2. **High — complete HTTP framing does not establish semantic SSE safety for native POSTs.** `core/providers/utils/utils.go:4414-4451` still makes clean EOF without a terminal event a retryable 502. If upstream sends only an SSE comment or an incomplete event and then ends HTTP cleanly, no response chunk need reach `CheckFirstStreamChunkForError`; it converts that first error into a retry, and `executeRequestWithRetries` classifies 502 as transient. Thus a POST that has produced wire bytes and may have been processed can be sent again. Unlike the repaired missing-zero-chunk path, this is a source-derived scenario, not independently reproduced in this review. Require an end-to-end native physical-send counter for clean HTTP EOF after non-emitted bytes, as well as malformed framing, and a no-replay decision based on actual attempt state rather than terminal semantics alone. Native clean EOF after an emitted output chunk is returned to the consumer without first-chunk replay.
